# erben-gpt

A hands-on study of **LLM scaling laws**: how to choose the model size and training-token budget for a given amount of compute, and how loss improves as compute increases.

The project also explores GPT architecture by implementing and training language models from scratch.

Every line of the model and training code is hand-written by me as part of the learning process. The report and deployment tooling were created with AI assistance.

[Read the interactive scaling law study](https://erbenmo.github.io/erben-gpt/).
